# Unidad 2 - Ruta de aprendizaje 2

## Proyectos
- **DiceRoller**: app que lanza un dado y muestra la imagen según el resultado.
- **Lemonade**: app interactiva para preparar limonada en 4 pasos.

## Temas aplicados
- Estado con `remember` y `mutableStateOf`
- Recomposición en Jetpack Compose
- Modificador `clickable`
- Composables reutilizables con parámetros y lambdas
- Recursos de cadenas (`strings.xml`) y accesibilidad (`contentDescription`)
